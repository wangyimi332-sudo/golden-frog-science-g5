# California Science G5

California Science Grade 5 是一套以科学问题带动英语学习的五年级课程。孩子从显微镜下的细胞出发，追踪植物怎样吸收水、制造食物，人体各系统怎样协作，再把视线移向加州的水资源、天气、太阳系和物质变化。每一课都要求先看现象与图像，找出可以支持结论的证据，再用英语解释“为什么”，逐步学会区分观察、推断与尚未回答的问题。加州供水专题把这一方法放进真实感的公共议题：修复漏水、再生利用与增加取水各能改变什么，模型没有测量到谁的需要和哪些生态影响。课程的核心是让孩子像小研究者一样阅读科学、比较方案并说清自己的理由，而不只是记住术语。

## 学习方式

全册31课开放。每课以英文阅读为主，中文小字辅助理解，包含可探索的主题图、科学词卡、分类操作、证据判断、句子拼接、主张—证据—推理写作和螺旋复习。每章另有原创科学与社会阅读，英文文章使用预录 AI 配音。孩子与家长各有独立本地档案，可导出备份。

## 启用 GitHub Pages

1. 打开已上传的仓库，进入 Settings → Pages。
2. 将 Build and deployment 的 Source 设为 GitHub Actions。
3. 在 Actions 中重新运行 Publish website，成功后再使用 Pages 网址。
4. 用手机无痕窗口核对首页、课程、图片和音频。

本包已经编译，无需在 GitHub 安装 Node。仓库可见性与账户方案须支持 Pages。正式托管与本地电脑是否开机无关。

源码在项目的 site/src。学习数据只保存在当前浏览器和网址；换网址或设备前导出 JSON。开放写作由学习者自检，不提供自动评分。音频为 Kokoro Heart AI 配音；图像为 AI 情境示意，不作精确测量。
